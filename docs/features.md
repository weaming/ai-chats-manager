# AI Chats Manager 功能概览

本系统是一个基于 Vue 3 和 TypeScript 开发的 AI 对话管理工具，旨在提供流畅的本地对话管理、编辑与分享体验。

## 核心功能

### 1. 对话文件管理
- **文件系统访问**: 使用 File System Access API 直接读写本地 JSON 格式的对话文件。
- **目录树浏览器**: 支持无限层级的文件夹结构，提供文件系统的树状视图。
- **文件操作**:
    - 创建新对话。
    - 文件/文件夹重命名。
    - 自动保存与状态恢复（通过 IndexedDB 记录最后打开的文件夹和文件）。

### 2. 对话交互与预览
- **多维度视图**:
    - 列表视图展示完整的问答流。
    - **智能目录 (Smart TOC)**: 提供可拖拽、可缩放的目录导航，支持折叠展开，并与正文实时滚动同步。
    - 支持 Markdown 渲染，包括代码块、数学公式、表格等。
- **交互操作**:
    - **拖拽排序**: 支持通过拖拽调整问答回合的顺序。
    - **跨文件移动**: 支持将问答回合拖拽到侧边栏的其他文件中。
    - **行内编辑**: 点击即可编辑问题或 AI 回答，支持实时预览。
    - **多选管理**: 支持批量选择、全选、反选以及批量删除。
    - **UI/UX 优化**: 统一的大字号编辑体验、全局快捷键支持、以及更现代化的操作页眉。

### 3. Markdown 处理工具
- **格式修复**: 提供一键修复 Markdown 间距（如中西文间距）的功能。
- **差异对比**: 支持以可视化按钮切换源码对比或渲染预览，文字清晰。

### 4. 导出与分享
- **图片生成**: 支持将选中的问答回合生成精美的长图 (PNG)。
- **分享预览**: 提供专门的预览页面，支持自定义编号显示规则，确保导出图片的效果。
- **表格优化**: 导出的图片完整保留 Markdown 表格的边框与样式。

### 5. 数据兼容性
- **解析器**: 内置 Gemini 等常见 AI 平台的导出数据解析器，支持数据导入与迁移。
- **导入体验**: 支持文本直接粘贴导入，具备自动聚焦、快捷键操作（Esc 取消/Enter 确认）等高效特性。

## 技术栈
- **前端框架**: Vue 3 (Composition API)
- **状态管理**: Pinia
- **构建工具**: Vite
- **核心库**:
    - `marked`: Markdown 解析。
    - `html-to-image`: PNG 生成。
    - `idb-keyval`: 状态持久化。
