# 项目设计文档：Gemini 分享图生成器

本文档详细描述了 Gemini 分享图生成器项目的设计需求和功能规格。

## 1. 核心目标

开发一个纯静态网站工具，帮助用户方便地将其与 Gemini 的对话内容生成精美的、便于分享的 PNG 图片。该工具完全在用户本地运行，无需任何后端服务。

## 2. 技术规格

-   **前端框架**: Vue.js
-   **编程语言**: TypeScript
-   **构建目标**: 生成一个 `dist` 目录，包含所有静态资源（HTML, CSS, JS），可部署在任何静态文件托管服务上。

## 3. 数据存储与结构

-   **存储方式**: 使用浏览器的 File System Access API，所有数据直接读写用户在本地文件系统上授权的一个文件夹。
-   **根目录结构**: 在用户选择的根目录下，自动维护以下结构：
    ```
    /用户选择的根目录
    ├── chats/
    │   ├── 20250101-0808-uuid.json
    │   └── folder1/
    │       └── 20250102-1030-uuid.json
    └── markdown/
        ├── 1-hash1.md
        ├── 2-hash2.md
        └── ...
    ```
    -   `chats/`: 存放对话的元数据（JSON 文件）。
    -   `markdown/`: 存放所有 Gemini 回答的具体内容（Markdown 文件）。

## 4. 文件格式与关联

-   **对话文件 (JSON)**:
    -   文件名格式: `YYYYMMDD-HHmm-xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.json`。
    -   文件内容: 一个数组，按顺序记录每一轮对话。
        ```json
        [
          {
            "question": "用户的第一个问题",
            "answer_id": "1-abcdef12" 
          },
          {
            "question": null, // 问题可以为空
            "answer_id": "2-fedcba21"
          }
        ]
        ```
-   **回答文件 (Markdown)**:
    -   文件名格式: `[对话序号]-[内容hash].md`，与 JSON 中的 `answer_id` 对应。
    -   文件内容: Gemini 回答的原始 Markdown 文本。

## 5. 核心功能与流程

### 5.1. 对话创建（手动录入）

1.  **新建对话**: 用户点击“新建对话”按钮。
2.  **数据粘贴**: 界面显示两个文本输入框：“问题”和“回答”。
3.  **录入规则**:
    -   “回答”框（Markdown 文本）为必填项。
    -   “问题”框为选填项。
4.  **添加条目**: 用户点击“下一条”按钮，应用将当前输入框中的内容保存到内存中，并清空输入框以便录入下一组问答。
5.  **完成创建**: 用户完成所有问答录入后，点击“完成”按钮。此时，应用会：
    -   生成一个新的对话 JSON 文件并存入 `chats` 目录。
    -   将每一条回答分别生成对应的 Markdown 文件存入 `markdown` 目录。

### 5.2. 对话浏览与渲染

1.  **文件列表**: 应用启动后，展示 `chats` 目录下的文件和文件夹结构。
2.  **渲染对话**: 用户点击一个对话 JSON 文件时，应用会读取该文件及其关联的所有 Markdown 文件。
3.  **界面呈现**: 对话内容将以类似 Gemini 官网的问答气泡样式显示在主界面。

### 5.3. 分享图生成

1.  **选择内容**:
    -   用户可以在渲染出的对话界面上勾选想要分享的内容。
    -   选择的基本单位是“问答组”（一个用户问题 + 一个 Gemini 回答）。
    -   点击问答组的任意部分，会默认同时选中问题和回答。
    -   用户可以随后手动取消对“问题”部分的选择，只保留“回答”。
2.  **生成图片**:
    -   用户点击“分享”按钮。
    -   应用将所有选中的内容，根据一套**独立的样式**，渲染并生成一张 PNG 图片供用户下载。
3.  **样式定制**:
    -   生成图片所用的 CSS 样式将保存在一个独立的、易于修改的文件中（例如 `share-style.css`），与应用主界面的样式分离，方便用户未来进行个性化定制。

## 6. 管理功能

-   **对话重命名**: 用户可以重命名对话，对应的 JSON 文件名会同步更新。
-   **文件夹管理**: 用户可以在 `chats` 目录下创建、移动和删除文件夹来组织对话，应用界面会同步反映这些变化。
